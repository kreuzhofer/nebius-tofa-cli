What the runnable experiment established

The installed bundled engine preserved both session identities, titles and workspace associations across ordinary → tofa → ordinary → tofa launches. Native continuation used the native route. Tofa continuation failed explicitly without its provider, then succeeded using a fresh temporary route. Synthetic config and auth files stayed unchanged; expired listeners closed.

Desktop result: this wrapper needs revision. Actual desktop startup persisted its temporary executable path into shared tool settings. Cleanup leaves a stale path. Engine-only preservation does not establish desktop preservation. See desktop-evidence.json.

A later human walkthrough confirmed tofa continuation and recovery after relaunch. We corrected argument placement that had caused the active tofa launch to lose its provider. Ordinary mode still loops when opening the tofa history item. See human observations and diagnosis.

The merged catalog retained the shipped native model descriptors. This is a bundled snapshot, not a live account catalog. Desktop auxiliary requests for native models under the tofa provider remain a routing question; this prototype rejects mismatches.
