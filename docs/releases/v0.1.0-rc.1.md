## Limits and retained failures

All six binaries have cross-build evidence. Native lifecycle execution covers
macOS ARM64, Linux amd64 and Windows amd64. Real-machine qualification covering vault access and live
Codex remains pending in #23; these results do not establish
that qualification. Apple and Windows publisher signing remain deferred.

An earlier [main run at 4b756af](https://github.com/kreuzhofer/nebius-tofa-cli/actions/runs/35641127779)
failed Windows' initial fresh-shell discovery probe at its 10-second process
deadline, before installation. The underlying cause remains unconfirmed. That
failure is retained, not counted as a pass. The subsequent main and tag workflows
both passed the unchanged Windows lifecycle test (the main lifecycle step took
16 seconds in total).

An optional post-publication local install-and-purge check was rejected by
automatic approval review because it overrode HOME and performed a destructive
purge. It was not executed. Post-publication verification therefore covers
downloads, checksums, byte identity and binary version; lifecycle evidence comes
from the required native CI jobs.

### macOS ARM64

Requires Python 3.9+, `curl`, authenticated `gh` and Codex on PATH.
In a new checkout:

```sh
gh repo clone kreuzhofer/nebius-tofa-cli tofa-qualification-rc1
cd tofa-qualification-rc1
git checkout --detach 34e1155425bc54a22af6d930151b4409f21520fa
git rev-parse HEAD
python3 scripts/qualify_macos.py \
  --version v0.1.0-rc.1 \
  --output "$HOME/tofa-macos-rc1-$(date +%Y%m%d-%H%M%S).json"
```

At `FOUND`, check `command -v tofa` and `tofa --version` in a new terminal
against the runner's prompt. Expected binary SHA-256:
`9fb767d34b861298f3d5b97aff08f89392dbae75a2249c3d1c3fc3c09a21541f`.

### Windows 11 amd64

Requires Python 3.9+, authenticated `gh`, Windows PowerShell 5.1, the Windows
.NET Framework C# compiler and installed Codex. No Go installation is needed.
In PowerShell, in a new checkout:

```powershell
gh repo clone kreuzhofer/nebius-tofa-cli tofa-qualification-rc1
cd tofa-qualification-rc1
```
