# v0.1.0-rc.12 — experimental macOS desktop candidate

Candidate source: `c4601ee60f0bd29932cb194f241b7e694fb6ecff`.
This candidate is installed and undergoing qualification for
[#35](https://github.com/kreuzhofer/tofa-launcher/issues/35). It is not published.

DeepSeek V4.1 Flash image requests failed upstream when Codex omitted an output
limit. This build supplies `max_output_tokens: 32768` only for image-bearing
requests to that model when the field is absent. The limit includes reasoning
and answer tokens. A once-per-launch terminal notice explains the workaround.
Explicit values, including null, are preserved. Text-only requests and other
models are unchanged. Native response, reasoning, incomplete and error events
pass through unchanged; the adapter neither retries nor edits response text.
This is an approved launcher default, not a verified provider output ceiling.
Attached images and images returned by native function/custom tools are covered.

The candidate also retains the minimum-version desktop compatibility, updated
engine discovery/startup handling, independent conversation models, Experimental
picker entries, CLI-default isolation, assistant-history IDs and GLM 5.3
provider-managed thinking changes recorded in the [rc11 report](v0.1.0-rc.11.md).
Rc11 failed image qualification and was not published. Its passing observations
remain historical evidence, not rc12 UI results.

## Installation after publication

These commands become usable only after this prerelease is published:

```sh
curl -fsSL https://github.com/kreuzhofer/tofa-launcher/releases/download/v0.1.0-rc.12/install.sh -o install.sh
sh install.sh --version v0.1.0-rc.12
tofa launch codex-desktop
```

Quit the desktop before launching. Use a fresh terminal if the installer added
PATH activation. Saved login is reused; first installations use `tofa auth login`.
The launcher picker chooses the initial default; eligible models remain available
in the desktop picker. Keep the launcher terminal open. Normal desktop quit ends
the launch. `tofa uninstall` without `--purge` retains login and preferences.

The frozen bundled README retains historical rc2 installation sections from
the source snapshot. Use this candidate's release instructions for rc12; later
qualification notes do not rebuild or replace frozen assets.

## Limitations

This remains experimental. Qualification is limited to the recorded macOS
combination.
Experimental model labels remain; short checks do not establish stable support.
DeepSeek/GLM automatic naming and unrecognized auxiliary requests remain
unsupported. Only the previously captured Kimi title contract has an auxiliary
route. Compaction is explicitly unsupported and rejected before upstream
inference; [#72](https://github.com/kreuzhofer/tofa-launcher/issues/72) tracks
research. Actual provider context/output limits are not stress-qualified.

Text-only models omit saved images from inference with a terminal notice, while
history retains them for later image-capable models. GLM 5.3's native `None`
setting uses provider-managed thinking with a notice, preserving native channels.
Native and Token Factory providers do not migrate when model selections change.
Catalog changes require relaunch. Native deadlines, permissions and managed
policy remain in force; signing and notarization are not provided. Windows
desktop and the separate CLI qualification in #23 are not established here.
