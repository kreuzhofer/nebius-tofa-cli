Candidate source: `a6e65a2ae6e8d96f2399ef572902be6acad3c401`.
[Published experimental prerelease](https://github.com/kreuzhofer/tofa-launcher/releases/tag/v0.1.0-rc.13)
for [#35](https://github.com/kreuzhofer/tofa-launcher/issues/35). The public installer
and all downloaded assets were verified against the frozen qualified candidate.

The desktop picker uses `(Token Factory)` for supported choices and
`(TF Experimental)` for experimental choices. Nemotron displays as
`Nemotron 3 Ultra`; its full model ID remains unchanged. This avoids the longer
rc12 labels that the user found clipped.

This build includes minimum-version desktop compatibility, updated bundled-engine
discovery, independent conversation models, all eligible experimental choices,
and isolation of desktop model/reasoning defaults from concurrent CLI sessions.
It repairs missing assistant-history IDs, preserves GLM 5.3 native reasoning via
the announced provider default, and adds the approved 32,768-token limit only to
DeepSeek V4.1 Flash image requests that omit `max_output_tokens`. Explicit limits,
including null, remain unchanged. That limit covers reasoning and answer tokens;
it is a launcher workaround, not a verified provider maximum. Native response
streams, including incomplete/error events, are preserved without retry or text
filtering.

## Installation

Install this exact prerelease:

```sh
curl -fsSL https://github.com/kreuzhofer/tofa-launcher/releases/download/v0.1.0-rc.13/install.sh -o install.sh
sh install.sh --version v0.1.0-rc.13
tofa launch codex-desktop
```

Quit the desktop before launch. Use a fresh terminal if the installer added PATH
activation. Saved login is reused; first installations use `tofa auth login`.
The launcher picker selects the initial default; the desktop picker retains every
eligible model. Keep the launcher terminal open. Quit with the app's Quit command
or ⌘Q; closing its window alone can leave the process running. `tofa uninstall`
without `--purge` retains login and preferences.

The frozen bundled README retains historical rc2 installation sections from its
source snapshot. These release instructions are authoritative for rc13. Later
qualification notes never rebuild or replace frozen assets.

## Boundaries

This is an experimental prerelease, not a stable-support promotion. GLM 5.3 Flash,
Kimi and Nemotron retain Experimental labels; appearing in the picker or passing
a short check does not qualify every combination. Models without compatible
metadata are omitted with an explicit explanation.

DeepSeek/GLM automatic naming, unrecognized auxiliary requests and compaction
remain unsupported. Only the previously captured Kimi automatic-title contract
has an auxiliary route. Recognized compaction fails before upstream inference
with context/new-conversation guidance; [research #72](https://github.com/kreuzhofer/tofa-launcher/issues/72)
tracks a compatible path. Actual provider context/output limits are not stress-tested.
Text-only models omit images from inference with a terminal notice while retaining
them in history. GLM 5.3's native `None` uses announced provider-managed thinking.
Other explicit controls remain unchanged. Native/Token Factory providers do not
migrate when selections change. Catalog changes require relaunch. Native deadlines,
permissions and managed policy remain enforced; signing/notarization are not provided.
