# v0.1.0-rc.14

Published prerelease at `14134d43df4cca00bcdf10e49b3dc5ef3122f8d7`.
[Release](https://github.com/kreuzhofer/tofa-launcher/releases/tag/v0.1.0-rc.14) ·
[passing checks/publication](https://github.com/kreuzhofer/tofa-launcher/actions/runs/36869208342).

Fresh interactive launches authenticate before app/model selection and continue
the same invocation. Saved logins skip onboarding; existing credential errors
remain explicit recovery conditions. Invalid arguments/platforms are checked
before credential collection. Noninteractive launches include login guidance.

All 17 checksummed release downloads were verified after publication. Actual
installers and the downloaded ARM64 binaries passed live catalog onboarding,
same-invocation synthetic target launch, and saved-login reuse on macOS 26.6.2
ARM64 and Windows 11 ARM64 build 26200 in UTM.

[Full #74 evidence and limitations](../evaluation/onboarding-74-2026-10-01.md)
include hashes, regression tests, native vault checks, cleanup and the Windows
guest MTU diagnosis. The guest uses IPv4 MTU 1200 to resolve its observed TLS
handshake timeout; TLS verification remains enabled. CurrentUser RemoteSigned
was explicitly requested by the maintainer.

These catalog checks perform no inference. The subsequent [CLI lifecycle
qualification](../evaluation/rc14-cli-2026-10-01.md) passed bounded live coding and
Guardian checks on macOS before and after reinstall. Windows live acceptance
remains gated on native sandbox setup, so #23/#15 stay open. CLI combinations
remain Experimental.
Desktop behavior/evidence is carried from [rc13](v0.1.0-rc.13.md); this release
does not establish Windows desktop support or stable-release status.
